# Glossary

| Term | Meaning |
|---|---|
| **AA** | Account Aggregator — RBI-licensed consent manager between FIPs and FIUs |
| **Anumati** | Perfios AA Pvt Ltd; our AA sponsor |
| **Perfios** | Analytics + FIU gateway + Hub APIs sponsor |
| **FIP / FIU** | Financial Information Provider (bank, insurer) / User (us, via regulated partner) |
| **ReBIT** | Technical standards body for AA APIs |
| **DPDP** | Digital Personal Data Protection Act 2023 + Rules 2025 |
| **DLA directory** | RBI list of registered Digital Lending Apps |
| **SACHET** | RBI portal for complaints about unregistered lenders |
| **BSA** | Perfios bank statement analysis (fallback route) |
| **Household Twin** | Dated picture of income, bills, cash, debt, protection, goals |
| **E01–E16** | Engines; see TechSpecifications.md |
| **Aaj ka kaam** | Today's one action |
| **Kyon?** | "Why?" card: what we saw, the rule, how sure, advice label |
| **Karo / Baad mein** | Do it / Later |
| **Agar…?** | What if — scenario simulator |
| **Sirf andaaza** | Scenario only — not the real plan |
| **Pakka / Andaaza / Pata nahi** | Confirmed / Estimate / Unknown |
| **Gullak** | Clay piggy bank — goal savings jar |
| **Paisa Points** | Habit points; no cash value |
| **Beej → Ankur → Paudha → Ped → Bargad** | Levels: Seed → Sprout → Plant → Tree → Banyan |
| **Resilience Days** | Days essentials are covered with no income |
| **Safe to Spend** | Lowest projected balance before next salary minus safety floor |
| **Poora / Sirf total / Sirf mere liye** | Sharing levels: Full / Totals only / Private |
| **Aasaan / Saathi / Pro** | Literacy modes |
| **Jaankari / Referral** | Education / routed to a licensed professional |
| **High Stakes Gate** | Read-back + confirmation before any action |
| **Recommendation Firewall** | Ranking never sees commission |
| **Value Ledger** | Evidenced money outcomes, separate from points |
| **Madad chahiye?** | Need help? — human route on every screen |
